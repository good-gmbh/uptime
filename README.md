# GOOD Uptime

Prüft alle 10 Minuten von außen, ob **workspace.good.gmbh** erreichbar ist (inklusive Datenbank) und ob das
TLS-Zertifikat noch mindestens 20 Tage gilt. Bei einem Fehler meldet sich GitHub per Mail.

Bewusst öffentlich: Das Repository enthält keine Daten und keine Geheimnisse, nur den Prüf-Workflow.
Die gepflegte Fassung liegt im (privaten) Repository GOOD Workspace unter `deploy/uptime/uptime.yml`.
